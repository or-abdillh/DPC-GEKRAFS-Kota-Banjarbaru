## 2. Analisis Kehadiran Digital Saat Ini

- **Website Lama:** Belum memiliki platform mandiri terintegrasi. Komunikasi masih terfragmentasi via Instagram dan grup WhatsApp internal.
- **Aktivitas Media Sosial:** Sangat aktif mempublikasikan kegiatan lokal (seperti *Banua Creative Festival*, pameran kriya, temu komunitas kopi, dan workshop pemuda kreatif), namun belum ada repository portofolio karya terstruktur.
- **Isu Kritis Teridentifikasi:**
  1. *Fragmentasi Data:* Pelaku ekraf kesulitan mendaftarkan profil usaha secara terverifikasi.
  2. *Kurangnya Akses Investasi:* Karya berkualitas (fesyen sasirangan modern, kriya purun kontemporer, produk kopi lokal, studio game/IT) belum memiliki etalase pitching terkurasi untuk investor luar daerah.
  3. *Advokasi Kebijakan Belum Berbasis Data Real-Time:* Pemerintah Kota Banjarbaru membutuhkan agregasi data statistik riil sebaran 21 subsektor ekraf untuk penyaluran bantuan, sertifikasi HKI, dan permodalan.

## 3. Penawaran Inti (Core Offerings & Modul Platform)

Platform digital `gekrafsbjb.com` dirancang dengan 5 modul utama (berdasarkan Initial PRD klien):

1. **EPIC 1: Portal Pelaku Kreatif & Database Mandiri (P0 - Critical):**
   - Registrasi mandiri untuk individu maupun badan usaha/komunitas kreatif di Banjarbaru.
   - Formulir kuesioner pemetaan 21 subsektor ekonomi kreatif (identitas usaha, legalitas, skala bisnis, roadmap pengembangan).
   - Kepatuhan mutlak terhadap UU Pelindungan Data Pribadi (UU PDP No. 27/2022) dengan *Mandatory Data Consent*. Data profil detail dikuasai oleh pelaku kreatif (*self-service*).
2. **EPIC 2: Directory "Open for Investment" (P0 - Critical):**
   - Etalase kurasi proyek/karya yang siap menerima pendanaan modal kerja atau kemitraan strategis.
   - Komponen UI kartu proyek interaktif: nama karya, subsektor, tahap bisnis (Ide/MVP/Growth), nilai pendanaan target (Rp...), dan tombol kontak kurator *"Ajukan Minat"*.
3. **EPIC 3: Event & Program Listing Kalender Kreatif (P0 - Critical):**
   - Mode Pra-Acara: pengumuman agenda, jadwal, link registrasi/tiket, integrasi share.
   - Mode Pasca-Acara: galeri dokumentasi foto high-resolution, jumlah peserta, highlight karya, dan ulasan liputan pers.
4. **EPIC 4: Public Impact Analytics Dashboard (P1 - High):**
   - Metric counter publik transparan: total pelaku kreatif terdaftar, representasi 21 subsektor, total komunitas aktif, dan total estimasi nilai proyek.
   - Visualisasi agregat untuk bahan advokasi ke Pemko Banjarbaru dan dinas terkait (Disporabudpar & Dinkop-UMKM).
5. **EPIC 5: Profil Kelembagaan & Pengurus (P1 - High):**
   - Struktur kepengurusan DPC GEKRAFS Banjarbaru, komite 21 subsektor, visi-misi, serta saluran kemitraan resmi.

## 4. Keunggulan Kompetitif & Analisis Ekosistem (USP & Gaps)

- **Nilai Tambah Utama (USP):**
  - Satu-satunya platform resmi di Banjarbaru yang menyatukan **seluruh 21 subsektor ekraf** (17 subsektor konvensional + 4 subsektor baru era digital: *Teknologi Baru, Konten Digital, Sulih Suara, dan Modifikasi Otomotif* sesuai Perpres Rindekraf No. 37/2026).
  - Menjaga kerahasiaan data privasi sesuai UU PDP: publik hanya melihat ringkasan kurasi dan analitik agregat, sementara data sensitif aman di dashboard terverifikasi.
  - Membuka akses kemitraan nyata ke investor luar daerah dan institusi BUMN/Pemda.
- **Kelemahan Channel Sekarang:**
  - Akun media sosial cepat tertimbun postingan baru, tidak memiliki fitur pencarian subsektor, tidak memiliki direktori investasi yang terstruktur, dan tidak ada analitik data agregat.
- **Peluang Landing Page `gekrafsbjb.com`:**
  - Menghadirkan portal visual modern berstandar agensi tinggi yang merepresentasikan citra Banjarbaru sebagai Ibukota Provinsi yang modern, ramah pemuda, dan episentrum inovasi kreatif Kalimantan.
